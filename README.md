# 📄 AI Resume Screener Pro

An intelligent, AI-powered Streamlit web application designed to automate and streamline the candidate screening process. Upload multiple PDF resumes, match them against custom job descriptions, and generate ranked evaluations instantly.

---

## ✨ Features

* **Multi-PDF Parsing:** Fast text extraction from candidate PDF resumes.
* **Smart Matching:** AI-driven scoring mechanism to evaluate resume content against job roles.
* **Interactive UI:** Aesthetic, modern, and user-friendly Streamlit dashboard.
* **Ranked Results:** Displays structured candidate scores, strengths, and missing skills.
* **CSV Export:** Download screened candidate evaluation data with one click.

---

## 🛠️ Tech Stack

* **Language:** Python 3.14
* **Framework:** Streamlit
* **Libraries:** PyPDF2, Pandas, Scikit-learn / NLP models
